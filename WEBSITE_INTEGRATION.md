# Website Integration Guide (`tecnoclub.net`)

This document is for web maintenance agents, developers, and webmasters managing **`tecnoclub.net`**.

---

## 1. Permanent Download URL for `tecnoclub.net`

Do **NOT** hardcode specific version numbers (such as `v1.0.0`) in your website links. 

Use the **Permanent Latest Release URL** provided by GitHub CDN:

```
https://github.com/tecnoclu/g2i-for-wave/releases/latest/download/G2i-for-Wave-Setup.exe
```

---

## 2. Why This Link NEVER Needs to Be Changed

1. **Static URL**: The URL above is permanent and constant.
2. **Auto-Resolution**: GitHub's `/releases/latest/download/` endpoint automatically points to the installer `.exe` generated by the most recent release pipeline.
3. **Zero Website Maintenance**: When the app development team pushes a new version tag (e.g., `v1.0.1`, `v1.1.0`), GitHub Actions automatically builds the `.exe` installer and replaces the asset. Visitors on `tecnoclub.net` will instantly download the latest installer without requiring any updates to the website code!

## 4. How Development Agents Release a New Version

When releasing a new update:

1. Update the version field in `package.json` (e.g. `"version": "1.0.1"`).
2. Commit and push the tag to GitHub:
   ```bash
   git add .
   git commit -m "Release v1.0.1"
   git tag v1.0.1
   git push origin main --tags
   ```
3. GitHub Actions CI/CD automatically compiles `G2i-for-Wave-Setup.exe` and publishes it to GitHub Releases.
4. `tecnoclub.net` download button instantly points to the new `.exe`.
